À propos

AL-QURAN est une application gratuite de lecture et de rappel. Les textes et fichiers audio téléchargés sont conservés sur l'appareil lorsque le navigateur le permet.

Sources et attribution

Texte arabe : Tanzil Project, texte Uthmani, conservé sans modification. tanzil.net.

Traduction française : Muhammad Hamidullah via AlQuran Cloud. Les conditions de redistribution doivent être vérifiées avant diffusion commerciale.

Audio : récitations servies par AlQuran Cloud et leurs sources associées. Les droits des enregistrements restent ceux de leurs ayants droit.

Voix française : synthèse vocale masculine du téléphone, si disponible. Ce n'est pas un enregistrement humain fourni par AL-QURAN.

Hadiths et invocations : références indiquées dans l'application. Les traductions rendent le sens et peuvent varier selon les éditions.

DONNÉES

Confidentialité

Les textes et fichiers audio téléchargés peuvent être conservés dans le stockage privé du navigateur. Le chargement initial contacte AlQuran Cloud et les sources audio.

Si des publicités sont ajoutées, cette politique devra être mise à jour pour décrire précisément les données traitées et les choix de consentement.
